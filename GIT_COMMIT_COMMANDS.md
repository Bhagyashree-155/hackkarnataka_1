# Git Commit Commands for Login/Registration Feature

## Step 1: Navigate to Repository
```powershell
cd E:\5thSem\Hackathon-project\HK-13
```

## Step 2: Add All Changes
```powershell
git add .
```

## Step 3: Commit with Message
```powershell
git commit -m "Add user authentication and registration system

- Add login and registration pages with form validation
- Implement JWT-based authentication in backend
- Add MongoDB models for User, LoanApplication, Repayment, Document
- Create authentication middleware and protected routes
- Add eligibility checking utilities
- Implement EMI calculator
- Update dashboard to show user information
- Add logout functionality
- Integrate MetaMask wallet connection"
```

## Step 4: Push to Repository
```powershell
git push origin blockgenix
```

---

## Alternative: Simple Commit Message
