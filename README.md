# BlockGenix - Decentralized Micro-Lending Platform

A decentralized application (DApp) for micro-lending and credit tracking built on Ethereum/Polygon.

## 🚀 Features

- **Borrowers**: Request loans with specified amounts and terms
- **Lenders**: View, approve, or reject loan requests
- **Smart Contracts**: Handle loan creation, disbursement, and repayment
- **Immutable Records**: All transactions stored on blockchain
- **Modern UI**: Beautiful, animated interface with glassmorphism effects

## 📁 Project Structure

```
blockgenix/
├── frontend/          # React + Vite DApp UI
├── contracts/         # Solidity smart contracts
├── backend/           # Node.js backend (optional)
└── README.md
```

## 🛠️ Tech Stack

- **Frontend**: React.js, Vite, TailwindCSS, Framer Motion
- **Blockchain**: Solidity, Hardhat
- **Network**: Ethereum/Polygon Testnet
- **Integration**: Ethers.js
- **Wallet**: Metamask
- **Backend**: Node.js (optional)
- **Database**: Firebase/MongoDB (optional)

## 🚦 Getting Started

### Prerequisites

- Node.js (v16+)
- npm or yarn
- Metamask browser extension

### Installation

1. Install dependencies:
```bash
npm install
```

2. Compile smart contracts:
```bash
npm run compile
```

3. Deploy contracts locally:
```bash
npm run deploy
```

4. Start frontend development server:
```bash
npm run dev
```
